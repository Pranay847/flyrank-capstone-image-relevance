# AI Image Understanding & Content Matching Engine

A trustworthy, tenant-scoped image recommendation backend. It classifies a 45-image wildlife corpus, creates deterministic semantic embeddings, ranks images for posts, rejects subject mismatches, tracks per-call costs, and exposes an approval workflow.

```text
images -> durable job -> vision schema -> embeddings --+
posts  -------------------------------> embeddings --+--> rank --> mismatch guard --> review
                                                    costs + evidence
```

## Run

Requires Node.js 24+; there are no package dependencies or API keys.

```bash
npm run seed
npm start
```

Use `Authorization: Bearer reviewer-demo-token` and `X-Tenant-Id: demo`. Run `npm test` for all six published probes plus boundary and idempotency coverage.

## Evaluation result

The committed 10-post labeled set reports **top-1 precision: 1.00 (10/10)**. `Vulpes vulpes` maps to red fox, a forced wolf candidate is refused with a category-mismatch explanation, and an unrelated post returns `no confident match`.

## Corpus and model choice

The seed creates 45 licensed-placeholder corpus records across five animal categories. Metadata is generated by a deterministic fixture vision provider (pre-generated metadata path accepted in portal Q&A) so reviewers need no paid key. A production Gemini/Ollama adapter can implement the same `classify(image)` contract.

## Limitations

The repository does not redistribute third-party image binaries and the default provider is deterministic. The evaluator exercises the complete reliability pipeline, but visual model quality itself is outside the offline demo.
